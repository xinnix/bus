# 电子票二维码显示修复 + 核销链路打通 + 小程序码预留

## Context

用户购票成功后，电子票页只有票号和 6 位核销码（截图证实 QR 区域空白），且核票员需要能扫码核验。

调查结论：

- **核销链路后端+前端代码已完整存在**（未提交改动）：`GET /orders/:id` 动态签发 HMAC qrToken（apps/api/src/modules/order/order.controller.ts:65、ticket-token.ts）、核销员扫码核销 `POST /checker/verify` 双通道验票（apps/api/src/modules/checkin/checkin.service.ts:99）、小程序核销工作台（apps/miniapp/src/pages/checker/index.vue，uni.scanCode + 手输核销码）。API 为 nest --watch 运行，代码已是最新。
- **唯一断点是小程序端二维码渲染**：`QrCode.vue`（apps/miniapp/src/components/QrCode.vue）用 `uqrcodejs@4.0.7` 生成矩阵。静态分析编译产物（vendor.js/组件/wxml 均正确）+ 与 jsdelivr CDN 官方包比对发现：该 npm 包 UMD 工厂函数结尾缺少 `return b`（全文件 0 处），即 `module.exports = undefined` → 运行时 `new UQRCode()` 抛 TypeError 被 watch 吞掉 → QR 区域空白。此推断需在开发者工具 console 最终确认。
- 用户新增方向：后期要支持"核票员微信直接扫码拉起小程序核验"（小程序码 wxacode）。wxacode 必须后端调微信 getwxacodeunlimit 出图（wechat.service.ts:181 已有 generateMiniProgramCode 可参考），且小程序发布前对普通用户不生效 → 本次不实现，预留挂点并登记 backlog。

## 改动内容

### 1. 修复二维码渲染（apps/miniapp）

- **先复现确认根因**：开发者工具打开电子票页看 console 报错；若为 `UQRCode is not a constructor` 则执行下述换库方案，否则按实际报错调整（备选：矩阵计算移到页面脚本）。
- **换库**：`apps/miniapp` 移除 `uqrcodejs`，安装 `qrcode-generator`（API：`qrcode(0, 'M')` → `addData(data)` → `make()` → `isDark(row, col)` / `getModuleCount()`，typeNumber=0 自动档，UMD/ESM 出口完好、社区久经考验）。
- **改写 `src/components/QrCode.vue`**：
  - 保留 view 格子渲染（不依赖 canvas，工具/真机通用）；
  - 用 `isDark(r,c)` 替代 `cell.isBlack`；
  - 格子尺寸改为按 `420rpx 总宽 / moduleCount` 自适应（qrToken 约 200 字符 → ~45 模块，避免写死 6rpx 导致可扫性差）；白边（quiet zone）加大到 ~24rpx；
  - make() 包 try/catch，失败时展示降级提示（核销码数字已可见，不白屏）。
- **类型与清理**：删除 `src/types/uqrcodejs.d.ts`，新增 `qrcode-generator` 的 d.ts 声明；`package.json` 同步依赖。

### 2. 核销页预留小程序码挂点（apps/miniapp/src/pages/checker/index.vue）

- `onLoad(options)` 解析 `options.scene`（decodeURIComponent；未来 wxacode 的 scene=核销码）与 `options.code`；
- 核销员身份就绪（已有 token/openid 免密登录成功）后自动调用 `verify({ code: scene })`，结果复用现有 result-card 展示；
- 未登录则暂存 scene，登录成功后自动核销。改动约 20 行，无副作用。

### 3. 不做（登记 backlog）

- wxacode 后端出图接口、电子票页展示小程序码图片、env_version 按环境配置 → 写入 `docs/product/backlog.md`（设计要点：scene 用 6 位 checkCode（≤32 字符限制满足，verify 已支持 code 通道）、缓存生成图、page=pages/checker/index）。
