# 验票员身份检查与绑定（手机号一致性）

## Context

验票闭环（Checker 表、`/api/checker/*`、小程序核销页 `pages/checker/index`）已存在，但存在两个断点：

1. **身份不通**：普通用户（`type: 'user'` JWT）登录后无法知道自己是不是验票员；核销页只能手输路径访问，且每次都要手机号+密码登录。
2. **绑定缺失**：`Checker.openid` 字段在 schema 中预留但全库无读写逻辑。

按用户确认的方案：**绑定靠手机号一致性** —— 管理端录检票员（手机+姓名，已有 `CheckerListPage` 无需改动）→ 用户微信登录并绑定手机后，后端按 `User.phone === Checker.phone` 匹配，回填 `openid` 完成绑定 → 首页出现「验票工作台」入口 → 进入核销页免密直达工作台。

无 schema 变更（`openid` 字段已存在），无需迁移。

## 后端（apps/api/src/modules/checkin/）

### checkin.service.ts — 新增两个方法

**`identity(userId)`** — 检查 + 绑定：

1. 按 id 查 User（JWT validate 只返回 id，需查库拿 `openid`/`phone`）
2. 若 `user.openid` 有已绑定的 ACTIVE Checker（`checker.findFirst({ openid, status: 'ACTIVE' })`）→ 返回 `{ isChecker: true, checker: { id, name, phone } }`
3. 否则若 `user.phone` 匹配 ACTIVE Checker → **绑定**：`checker.update({ openid: user.openid })`（仅当 user 有 openid 且该 checker 尚未绑定；update 包 try/catch 兜底 openid 唯一冲突，冲突时放弃回填但识别结果仍有效）→ 返回 `{ isChecker: true, checker }`
4. 都不匹配 → `{ isChecker: false }`

**`openidLogin(userId)`** — 免密签发：查 user.openid 对应的 ACTIVE Checker，无则 `ForbiddenException('未绑定核销员身份')`；有则复用现有签发逻辑（`checkin.service.ts:25-29` 的 `{ sub, type: 'checker', name }` JWT）返回 `{ accessToken, checker }`。

### checkin.controller.ts — 新增两个端点

- `GET /api/checker/identity` + `POST /api/checker/openid-login`：`@UseGuards(JwtAuthGuard)`，新增 `assertUser`（`user.type === 'user'`，与现有 `assertChecker` 对称），响应由全局 `TransformInterceptor` 包成 `{ success, data }`，小程序照常读 `res.data`。

## 小程序（apps/miniapp/src/）

### api/ticketing.ts — checkerApi 扩展

- `identity()`: `http.get('/checker/identity', undefined, { showLoading: false })`（http.ts 默认自动带用户 token，无需手动 header）
- `openidLogin()`: `http.post('/checker/openid-login', {}, { showLoading: false })`

### utils/checkerIdentity.ts（新文件）

`refreshCheckerIdentity()`：调 identity 接口，`isChecker` 则写 storage `checkerIdentity`，否则移除；静默失败。`getCheckerIdentity()`：读 storage。login.vue 与 index.vue 共用。

### pages/login.vue

`navigateAfterLogin()`（L127，微信登录/完善资料/跳过三条路径的共同汇聚点）中 fire-and-forget 调 `refreshCheckerIdentity()`。

### pages/index.vue（首页，当前唯一可达的入口页面）

- `onShow`：有 `token` 时静默 `refreshCheckerIdentity()`（覆盖「登录早于本功能上线」的老用户）
- hero 下方新增入口卡片（仅 `isChecker` 时渲染）：`🎫 验票工作台 ›`，tap → `uni.navigateTo('/pages/checker/index')`

### pages/checker/index.vue

`onMounted`：若无 `checkerToken` 且有用户 `token`，调 `openidLogin()` 免密进入工作台（存 `checkerToken`/`checkerName`）；失败则静默回落到现有手机号+密码表单（保留作后备）。仅 onMounted 执行一次，避免手动「退出」后被立即自动重登。
